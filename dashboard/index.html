API Instructions

Use the Long-SUS model from a URL.

The hosted API returns CSV by default, so it can be opened in a browser, downloaded, or read directly by another dashboard.

Base URL

Start here

https://long-sus-api.onrender.com

Render free services sleep after idle time. The first request can take about a minute, then later requests are faster.

Population by age and sex

CSV rows for one projection year

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=threshold_age_60_all_eligible&target=Xc&factor=1.2&branch=analytic_arm&year=2050

This returns one CSV row per sex and age. The key columns are year, sex, age, population_count, treated_population_count, and untreated_population_count.

Treatment examples

Copy one URL and change the country, year, target, or factor.

Untreated baseline

No one starts treatment. Use this as the reference projection.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=no_one&target=none&factor=1.0&branch=analytic_arm&year=2050

Everyone treated immediately

Everyone alive at launch starts, and later births are treated from birth.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=everyone&target=eta&factor=0.8&branch=analytic_arm&year=2050

Threshold age

Everyone age 60+ starts. Younger cohorts start when they reach age 60.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=threshold_age_60_all_eligible&target=Xc&factor=1.2&branch=analytic_arm&year=2050

Custom threshold share

Only half of each cohort starts when first eligible at age 60.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=threshold_age_60_all_eligible&target=eta&factor=0.8&branch=analytic_arm&year=2050&threshold_age=60&threshold_probability=0.5

Age bands, immediate starts

35% of ages 20-39, 65% of ages 40-64, and 95% of ages 65+ start at each band edge.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=prescription_bands_absolute&target=Xc&factor=1.2&branch=analytic_arm&year=2050

Age bands, spread starts

Same target shares, but starts are spread through each age band.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=prescription_bands_equal_probabilities&target=Xc&factor=1.2&branch=analytic_arm&year=2050

Linear rollout

Eligibility starts at age 60. The treated share rises from 10% to 50% over 12 years.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=rollout_threshold_linear&target=eta&factor=0.8&branch=analytic_arm&year=2050

Custom logistic rollout

Use an S-curve coverage path and override the launch share, long-run treated share, and years to plateau.

https://long-sus-api.onrender.com/population-pyramid?country=World&scheme_id=rollout_threshold_logistic&target=eta&factor=0.8&branch=analytic_arm&year=2050&rollout_launch_probability=0.15&rollout_max_probability=0.55&rollout_takeoff_years=9

Yearly totals

CSV rows for population summaries

https://long-sus-api.onrender.com/population-size?country=World&scheme_id=threshold_age_60_all_eligible&target=Xc&factor=1.2&branch=analytic_arm

This returns yearly totals, including total_population, treated_population, treated_share, births, deaths, median_age, and old_age_share_65_plus.

Common parameters

Parameter What to put
countryWorld, USA, China, India, Israel, Italy, Brazil, Nigeria, South Africa, or Uganda
scheme_idno_one, everyone, threshold_age_60_all_eligible, prescription_bands_absolute, prescription_bands_equal_probabilities, prescription_bands_uniform_start_age, rollout_threshold_linear, or rollout_threshold_logistic
targeteta, eta_shift, Xc, or none. Use target=none only with scheme_id=no_one
factorIntervention strength, such as 1.2 for Xc or 0.8 for eta
yearProjection year, required for population-pyramid
threshold_ageOptional override for threshold and rollout examples
threshold_probabilityOptional treated share for threshold examples, from 0.0 to 1.0
rollout_launch_probabilityOptional launch-year treated share for rollout examples
rollout_max_probabilityOptional long-run treated share for rollout examples
rollout_ramp_yearsOptional timing control for linear rollout
rollout_takeoff_yearsOptional years-to-plateau control for logistic rollout
formatcsv by default; add format=json only if a program needs JSON
